# Zonnestuur Pro

Zonnestuur werkt de eerste **30 dagen volledig**. Daarna gaat hij verder als **Zonnestuur Basis**, of met een
licentie als **Zonnestuur Pro**.

| | Basis (gratis) | Pro (€ 49 per jaar) |
|---|:---:|:---:|
| Dashboard, verbruik en inzicht in teruglevering | ✓ | ✓ |
| Advies en batterijvergelijking op je eigen meterdata | ✓ | ✓ |
| Eén apparaat automatisch op zon-overschot | ✓ | ✓ |
| Klaar-tijd-garantie (warm water, auto geladen) | ✓ | ✓ |
| Alle apparaten automatisch | | ✓ |
| Slimme dagplanning op zon én uurprijzen | | ✓ |

| Thuisbatterij slim laden en ontladen | | ✓ |
| Omvormer begrenzen bij negatieve prijzen | | ✓ |
| Meldingen op je telefoon | | ✓ |

## Zo werkt kopen

1. Betaal € 49 via iDEAL (Mollie). *De betaallink verschijnt hier zodra de verkoop start.*
2. Je ontvangt binnen een werkdag je licentiesleutel per e-mail (begint met `ZS1.`).
3. Plak de sleutel in Zonnestuur onder **Instellingen → Zonnestuur Pro → Activeren**.

De sleutel wordt op je eigen Home Assistant gecontroleerd, zonder internet en zonder account. Zonnestuur blijft
volledig lokaal.
