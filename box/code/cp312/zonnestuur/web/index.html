Auto laden in de goedkoopste uren

Laadt je auto nu slim via een andere app, zoals Tibber of Jedlix? Kies dan:
  • Koppelen: Zonnestuur laadt. Zet slim laden in die andere app uit, anders sturen ze allebei.
  • Alleen meekijken: die app blijft laden, Zonnestuur laat live zien wat er gebeurt en rekent uit wat hij zelf had gedaan.
